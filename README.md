# AIVoice

Нейросетевой шумодав для микрофона: убирает вентилятор, гул и фоновый шум, а чистый голос отдаёт в OBS.

```
Микрофон → усиление → срез низких → шумодав → гейт → выравнивание громкости → лимитер → OBS
```

## Запуск

Запустите `dist\AIVoice\AIVoice.exe`. Python не нужен, но exe работает только вместе с папкой `_internal` рядом с ним, поэтому переносите папку `AIVoice` целиком.

Держите её там, где можно записывать файлы (например, на `F:\`, но не в `Program Files`): рядом с exe хранятся `settings.json` и `aivoice.log`.

Windows может показать окно SmartScreen, потому что у программы нет цифровой подписи: нажмите «Подробнее» → «Выполнить в любом случае».

Сворачивайте окно на панель задач, но не закрывайте: OBS находит программу по окну. Повторный запуск просто покажет уже открытое окно.

## Подключение к OBS

### Без установки драйверов: захват звука приложения

Подходит, если в поле «Выход» выбрано `Steam Streaming Speakers`. Это выбирается автоматически, если нет VB-Cable.

1. Запустите AIVoice.
2. В OBS: **Источники → + → Захват звука приложения (бета)**.
3. В поле **Окно** выберите `[AIVoice.exe]: AIVoice`.
4. В **приоритете совпадения окон** выберите вариант, где при несовпадении заголовка ищется окно того же исполняемого файла (Match title, otherwise find window of same executable).
5. Отключите ваш обычный микрофон в микшере OBS, иначе шум останется в эфире.

Важно: при таком подключении OBS получает весь звук программы. Включённый режим «Слышать себя» попадёт в эфир дважды, поэтому используйте его только для настройки, а не во время стрима.

### С VB-Cable: как обычный микрофон

Этот вариант подходит, если обработанный голос нужен ещё и в Discord или других программах.

1. Установите [VB-Cable](https://vb-audio.com/Cable/) и перезагрузите компьютер.
2. Нажмите «Обновить список» и выберите выход `CABLE Input`.
3. В OBS: **Источники → + → Захват входного аудиопотока → CABLE Output**.
4. Отключите ваш обычный микрофон в микшере OBS.

В этом режиме «Слышать себя» в эфир не попадает.

**Не используйте Steam Streaming Microphone как кабель:** этот драйвер понижает тон голоса более чем вдвое и добавляет 30 дБ. В списке выходов его нет намеренно.

## Настройки

| Настройка | Что делает | С чего начать |
|---|---|---|
| Модель | DPDFNet чище, RNNoise легче для процессора | DPDFNet; RNNoise, если растёт счётчик сбоев |
| Сила | Сколько шума убрать. Меньше 100% звучит естественнее | 100% |
| Усиление микрофона | Подъём до обработки. Шкала «Микрофон» в речи должна доходить примерно до жёлтой зоны и не упираться в край | 0 дБ |
| Срез низких | Убирает гул и удары по столу | 80 Гц |
| Шумовой гейт | Глушит всё тише порога. Порог показан белой меткой на шкале. Обычно не нужен | выкл |
| Выравнивание громкости | Сближает тихую и громкую речь | 30% |
| Громкость на выходе | Итоговый уровень | 0 дБ |
| Запас буфера | Больше — надёжнее, но с большей задержкой | 30 мс |

Настройки применяются сразу и сохраняются в `settings.json`.

Если растёт счётчик «сбои», увеличьте запас буфера до 50 или 100 мс, либо переключитесь на RNNoise.

## Задержка

Полная задержка на этом компьютере около 150 мс: примерно 60 мс занимает модель с блоком, остальное — буферы Windows и запас буфера. С RNNoise она примерно на 30 мс меньше. Если голос заметно расходится с видео, задайте в OBS **Расширенные свойства аудио → Сдвиг синхронизации**.

## Для разработки

Запуск из исходников: `run.bat` (нужен Python 3.11 или новее, окружение создастся само). Если настроить OBS на этот запуск, в списке окон будет `[pythonw.exe]: AIVoice`.

Сборка exe: `build.bat`. Она заменяет папку `dist\AIVoice` вместе с `settings.json` внутри, поэтому сохраните этот файл заранее, если он нужен.

Тесты:

```bash
.venv/Scripts/python.exe -m unittest discover -s tests
```

`tools/evaluate.py` и `tools/end_to_end.py` измеряют качество и задержку на записи речи (моно, 16 бит, 48 кГц). `tools/process_loopback.py` забирает звук тем же API Windows, что и OBS.

Сторонние модели и их лицензии перечислены в `aivoice/assets/NOTICE.txt`.
